STAGE P6 — DOWNLOAD GATE

Perubahan:
- Download addon user biasa melewati gate timer sebelum link file dibuka.
- Timer acak 10–20 detik.
- Setelah timer selesai, tombol menjadi “Lanjut Download”.
- Premium aktif, Admin, dan Owner melewati timer.
- Link file addon eksternal tetap sama.
- Penghitungan jumlah unduhan dilakukan saat download benar-benar dibuka.

Catatan keamanan:
Stage P6 adalah gate sisi frontend untuk alur pengalaman pengguna. Pemeriksaan keamanan server-side yang lebih kuat direncanakan pada Stage P9.
