# MC Addon Share — Stage L

Stage L menambahkan validasi addon sebelum data diproses.

Validasi mencakup slug, nama, tipe file, kategori, URL gambar/download, versi Minecraft, ukuran, tanggal, dan deskripsi. Validasi dilakukan di browser untuk umpan balik cepat dan di API untuk keamanan server-side.

Kategori yang diterima: addon, resource, peta, lainnya, apk.

Tidak menyertakan atau mengganti data.json. Pertahankan data.json yang ada di repository.
